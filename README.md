# 言霊文法帖 〜助動詞と係り結びの陣〜

古文文法の「助動詞の接続」と「係り結びの法則」を体感しながら楽しく学べる和風バトルアクションゲームです。
高校生が古典文法を楽しみながら学べるよう、短いセッションと繰り返し遊べる仕組みを多数用意しています。

## 遊び方

タイトル画面で「陣立て」（モード）を選んで出陣します。基本の流れは、提示された動詞の活用形に正しく接続する「助動詞の言霊（札）」を4枚の札から選んで攻撃することです。正解でコンボが伸び、ダメージが増えます。3連続正解で「係り結び一閃チャンス」が発動し、係助詞（ぞ・なむ・こそ等）に応じた結びの形を選んで大ダメージを与えます。

間違えた問題は「怨念」として記録され、苦手復習モードで間隔を空けて再出題されます。プレイ結果に応じて経験値（徳）が貯まり、朝廷の位階が上がっていきます。札ごとの習熟度や称号のコレクション要素もあります。

## モード一覧

| モード | 内容 |
|---|---|
| 本編討伐（全三幕） | 妖狐→烏天狗→藤原の大君の3体を順に討伐する基本モード |
| 百鬼夜行（無限サバイバル） | 倒すほど強くなる妖怪が無限に出現。何体祓えるかに挑む |
| 六十秒一閃（タイムアタック） | 制限時間60秒で得点を競うスピード勝負 |
| 日課祓い（デイリー） | 1日1セット全5問の日替わり修練。連続実施日数（ストリーク）を記録 |
| 斬撃一閃（サドンデス） | ミス1回で即終了。連続正解数の限界に挑む |
| 言霊の真価（意味識別） | 短い例文中の助動詞（む・べし・る/らる など）の意味を4択で判別する |
| 怨念回収戦（苦手復習） | 間違えた問題が1日→3日→7日の間隔で再出題されるSRS復習。3回正解で卒業 |
| 古文の間（例文読解） | 竹取物語・枕草子・徒然草・方丈記・源氏物語・奥の細道の実文から文法を問う |
| 型稽古（活用形トレーニング） | 動詞の指定された活用形（未然・連用・終止・連体・已然・命令）を選ぶ |
| 連戦の間（ボスラッシュ） | 本編3幕を敵HP1.5倍・気力回復なしで連戦する |

## 学習の仕組み

- **動詞の活用形見極め**: 出題される動詞（未然形、連用形、終止形、上一段・上二段・下二段・変格活用など）に正しく接続する助動詞を選択。全66問。
- **係り結び一閃チャンス**: 3連続正解（コンボ）で「ぞ・なむ・こそ」の係助詞フィーバーが発動。文末の結び（連体形・已然形）を選択して大ダメージ。形容詞・形容動詞・助動詞が述語になる問題も含め全17問。
- **意味識別**: 多義の助動詞の意味を文脈から判別する全26問。入試の本丸である意味の見分けを鍛えます。
- **SRS復習**: 誤答は自動で復習キューに登録され、間隔反復で再出題されます。
- **助動詞便覧**: いつでも開ける文法辞典（接続・意味・活用・覚え方・例文）。
- **本格和風サウンド＆演出**:
  - Web Audio APIによる和太鼓・神鈴・係り結びチャイム・被弾音の動的シンセシス。
  - キャンバス描画による優雅な桜吹雪アニメーション。

## 技術スタック

- React 19 + TypeScript
- Vite
- Web Audio API (オシレーター合成による効果音)
- HTML5 Canvas (桜吹雪エフェクト)

## 開発

```bash
npm install
npm run dev      # 開発サーバー（port 3000）
npm run build    # 型チェック + 本番ビルド
```

モードの追加は `src/modes/` に定義ファイルを作成し、`src/modes/registry.ts` の `MODE_REGISTRY` に登録するだけです（タイトル画面に自動で並びます）。セッション型モード（意味識別・復習・読解・型稽古）の出題は `src/modes/session.ts` の `SessionQuestion` で共通化されています。
