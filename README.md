# 言霊文法帖 〜助動詞と係り結びの陣〜

古文文法の「助動詞の接続」と「係り結びの法則」を体感しながら楽しく学べる和風バトルアクションゲームです。

## 主な特徴・ゲームシステム

- **動詞の活用形見極め**: 出題される動詞（未然形、連用形、終止形、上一段・上二段・下二段・変格活用など）に正しく接続する助動詞の言霊を選択。
- **係り結び一閃チャンス**: 3連続正解（コンボ）で「ぞ・なむ・こそ」の係助詞フィーバーが発動。文末の結び（連体形・已然形）を選択して大ダメージを与えます。
- **3幕構成の妖怪討伐**:
  1. 第一幕：妖狐の社（惑わしの白狐 🦊）
  2. 第二幕：深山の嵐（迷妄の烏天狗 👺）
  3. 大詰：怨霊の玉座（文法怨霊・藤原の大君 👻）
- **本格和風サウンド＆演出**:
  - Web Audio APIによる和太鼓・神鈴・係り結びチャイム・被弾音の動的シンセシス。
  - キャンバス描画による優雅な桜吹雪アニメーション。

## 技術スタック

- React 19 + TypeScript
- Vite
- Web Audio API (オシレーター合成による効果音)
- HTML5 Canvas (桜吹雪エフェクト)
